# SPOT Knight Hacks Challenge Assets

All images in this folder are synthetic and fictional, created for the Knight Hacks challenge.

- fictional_floor_plan.png - fictional two-floor facility map with WP01-WP15
- waypoint_reference_legend.png - waypoint reference table and zone-type legend

These assets do not represent a real NextEra Energy facility, production robot environment, or actual equipment.
